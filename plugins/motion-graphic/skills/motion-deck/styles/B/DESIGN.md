# 스타일 B 「지면」 — 흰 지면, AI 가 조판하고 사람은 주황 펜으로 고친다

> 흰 지면 위에 글이 줄 단위로 조판되고, 사람의 개입은 주황 펜 획(자리바꿈·취소선·삽입·동그라미·지시선)이다. 장치는 네이비 정밀선이다.
> 화면 보기: `preview.html`(더블클릭) · `shots/sheet.png` · 필름 `shots/*-film.png`. 덱 전체에 쓰는 공통 규칙은 `references/rules.md`.

## 언제 고르나
- **조명을 켠 회의실·강당**에 가장 안전하다(밝은 바탕의 어두운 글자는 나이와 관계없이 더 잘 읽힌다).
- 청중이 결재·교정·보고서에 익숙할 때 "사람 = 펜" 은유가 바로 통한다. 고치고, 승인하고, 반려하는 이야기에 잘 맞는다.
- 위험: 지면은 문서처럼 보이기 쉽다. 장마다 글자 양을 엄격히 묶어야 "보고서 같다"는 말을 피한다. 큰 카메라 이동의 쾌감은 A·C 보다 적다.

## 1. 화면
- 1920×1080, 바탕 흰색. **크롬 없음**(챕터 라벨·푸터·쪽번호·진행 바·범례 줄).
- **12단 그리드**: 좌우 여백 120, 단 118 + 간격 24. 단 왼쪽 x = 120 262 404 546 688 830 972 1114 1256 1398 1540 1682. 왼쪽 정렬 비대칭이다.

## 2. 색 (`theme.css` 의 `:root` 토큰)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | `#333` | 제목·본문·선(흰 바탕 12.6:1) |
| `--ink3` | `#666` | 보조 글자(5.7:1), 지나간 이름 |
| `--rule` | `#A4A3A4` | 구조선·갈 길 점선(글자로 쓰지 않는다 — 2.5:1) |
| `--green` | `#00854A` | **AI**. 흰 바탕 글자 가능(4.71:1) — 조판 글자·에이전트 |
| `--navy` | `#002060` | **장치·절차**. 절차 선·관문 |
| `--pen` | `#E36007` | **사람·주인공 = 주황 펜 획으로만**(흰 바탕 주황 글자는 3.53:1 로 불합격) |

- 그라데이션·그림자·글로우·블러 없음. 다른 브랜드 색으로 바꾸려면 토큰만 바꾼다(글자 색은 흰 바탕 4.5:1 이상 — 캡처 검사가 확인).

## 3. 조명 규칙(지면판)
- 지금 말하는 줄만 잉크 `#333` 굵게, 지나간 것은 `#666` 으로 물린다. 붙은 주석·지시선도 다음 단계에서 회색으로 물린다.
- 결론에서 읽혀야 할 글자는 켜 둔다.

## 4. 타이포
- 크기: 타이틀 290 · 큰 문장 150 · 결론 150 · 장 제목 104~120 · 여백 주석 84 · 설명 한 줄 60 · 정거장 이름 60 · 누가 46 · 꼬리표 44. 최소 40px(머리줄의 행사·발표자 정보만 32px 이상 허용).
- 굵기: 디스플레이 800, 제목 760, 설명 600.
- 자간: 디스플레이 −0.03em(250px 이상 −0.035em), 48px 이하 −0.01em. 라틴→한글 경계는 마지막 라틴 글자에 `.lk`(+0.015~0.02em).
- 행간 1.1~1.2. `white-space: nowrap` 을 기본으로 두고 줄은 손으로 나눈다(`keep-all`).

## 5. 모션
- **조판 와이프**: 글은 줄 단위로 왼→오 드러난다(`data-fx="wipe"`, FLIP 은 `data-b-wipe` 로 장 진입 때 줄마다 150ms 간격). 오른쪽 정렬 주석은 `wipe-l`.
- **펜 획**: 사람의 개입. 자리바꿈 부호(⊂), 취소선 `strike`, 삽입 부호 `caret`, 동그라미 `circle`, 밑줄 `underline`, 교정 지시선 `lead`(theme.js 가 정의, 고친 말 → 여백 주석 묶음). 획 0.28~0.62s. 제자리에 남아야 하는 자국은 정적 SVG + `data-fx="draw"`.
- **활자 자리바꿈**: FLIP 으로 낱말이 자리를 바꾼다(샘플: 주어 둘이 자리를 바꾸고, 지운 말 위에 새 말을 넣고, 여백에 주석이 붙는다).
- **장 전환**: 가로 밀기(reveal `slide`, 지면 넘김). 밀기가 장 진입 연출과 겹치면 체감 1.4s 까지 길어지므로 진입 연출은 짧게 둔다.
- 튕김 없음. 클릭당 1.2s 이하.

## 6. 기호
- 사람 = 주황 펜(체크·동그라미·밑줄) · AI = 초록 활자·초록 눈금 · 장치 = 네이비 막대(관문)·네이비 진행선
- 승인 지점 = 결재칸(흰 사각 + 잉크 테두리) — 대기 중이면 테두리가 주황, 승인되면 주황 체크
- 일감 = 잉크 꼬리표(작은 검정 태그)
