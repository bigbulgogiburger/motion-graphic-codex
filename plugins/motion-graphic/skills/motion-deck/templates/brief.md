# 브리프 — {{TITLE}}

> 이미 있는 자료(대본·개요·이전 발표)를 먼저 읽고 채운다. 빈 칸만 사용자에게 묻는다. 모르는 것은 기본값으로 두고 「기본값」이라고 적는다.

## 꼭 정할 것
- **주제와 한 문장 메시지**: 이 발표가 끝나면 청중이 기억할 한 문장
- **청중**: 누구인가 · 이 주제를 얼마나 아는가 · 직급과 나이대(말투와 글자 크기가 달라진다)
- **발표 시간**: 분(질의응답 제외)

## 기본값이 있는 것
- **발표자 한 줄**: 이름 · 소속. 타이틀 장에만 둔다
- **행사 이름 · 날짜**
- **장소**: 밝은 회의실 / 암전한 홀 / 모름 → 스타일 고를 때 쓴다. 기본값은 모름이고, 이때는 밝은 바탕을 권한다
- **스크린 크기 · 맨 뒷자리 거리**: 모르면 글자는 읽는 문장 48px 이상, 최소 32px 로 간다
- **스타일**: A 「무대」 / B 「지면」 / C 「색면과 도형」 — 2단계에서 고른다
- **색**: DB Inc. 팔레트(기본). 다른 브랜드 색이 있으면 색 코드를 받는다
- **납품 경로·파일 이름**: 기본은 `dist/<영문 짧은 이름>.html`

## 내용 재료
- **꼭 들어갈 내용**: 사례·숫자·화면. 출처도 함께 적는다
- **써도 되는 사실**: 검증된 연도·제품·수치만. 나머지는 화면에 "~"로 흐리게 쓰거나 질문으로 남긴다
- **숨길 것(금칙어)**: 고객사·사람 이름·내부 코드·도메인·금액 등. `deck/meta.json` 의 `forbidden` 에 넣는다
  - 금액·도메인을 통째로 막으려면 `anonymize: true`
- **단정할 수 없는 것**: 사내 규정·정책 등은 "점검 항목"으로만 쓴다
- **사진·일러스트가 꼭 필요한 장면**: 대부분은 SVG/CSS 로 그린다
