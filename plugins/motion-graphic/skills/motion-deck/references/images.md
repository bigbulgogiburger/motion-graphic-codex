# 사진·일러스트 — 꼭 필요할 때만, Codex가 직접 만든다

## 먼저 묻는다: 직접 그리면 안 되나
- 도식·아이콘·화면 흉내(창·체크 목록·카드)·기호는 **직접 만든 SVG/CSS** 가 기본이다. 스타일과 같은 선 굵기·색으로 그려져야 한 시스템으로 읽힌다.
- 사진·일러스트는 장면에 *실물*이 꼭 필요할 때만 쓴다(장소, 사람의 손, 실제 물건의 질감). 덱 전체에 8장 안팎이 상한이다.
- 스톡 느낌의 3D 렌더, 유리·네온·파티클 이미지, 의미 없는 배경 이미지는 쓰지 않는다(`rules.md` 8절).

## 요청서 — `story/image-requests.md`
이미지 하나마다 아래를 구체적으로 쓴다. 모호한 요청은 "AI 이미지 같은" 결과를 낳는다.
- **장 sid · 파일 이름**(`deck/img/<이름>.webp`)
- **용도**: 화면에서 무엇을 말하려고 넣는가
- **구도**: 무엇이 화면 어디에, 얼마나 크게 있는가. 글자를 얹을 빈자리는 어디인가
- **톤**: 스타일의 바탕(검정/흰색)과 팔레트에 맞춘 색·밝기·질감. 사진인지 일러스트인지
- **비율·크기**: 예: 16:9, 1920×1080 또는 960×1080(반 화면)
- **금지**: 이미지 안의 글자, 실존 브랜드 로고, 실존 인물, 워터마크

## 만들기 — Codex에서 직접
- 현재 세션에 이미지 생성 도구가 있으면 `story/image-requests.md`를 읽고 직접 만든다. `imagegen` 스킬이 제공되면 그 지침을 따른다.
- 생성 결과를 `deck/img/<이름>`에 저장한다. 도구가 파일을 다른 곳에 저장하면 실제 결과 파일을 프로젝트로 복사하고 아래 검사로 이어 간다.
- 직접 생성 도구가 없고 **Herdr 안이면** 이미지 생성 도구를 쓸 수 있는 Codex pane에 맡긴다(추가 pane 3개 상한에 포함).
  ```bash
  herdr agent start img --kind codex --pane <pane id> -- -m gpt-6.1-sol -c model_reasoning_effort=xhigh
  herdr agent prompt img "story/image-requests.md 의 요청대로 이미지를 만들어 deck/img/ 에 저장하고, 끝나면 파일 목록만 답해라."
  ```
- 사용할 이미지 생성 도구가 없으면 요청서만 남기고 사용자에게 알린다.

## 받은 뒤
- 직접 열어 본다. 요청과 다르거나 "AI 이미지 느낌"이 나면 요청서를 고쳐 다시 만든다.
- 용량을 줄인다(한 장 500KB 안팎, webp/jpg). 단일 파일 전체는 40MB 이하다.
- 장에서는 상대경로(`img/<이름>.webp`)로 쓴다. 빌드가 data URI 로 넣는다.
- 이미지 위의 글자는 대비 4.5:1 을 지켜야 한다. 캡처 검사가 이미지 바탕은 못 재므로 직접 확인한다. 필요하면 글자 뒤에 단색 면을 둔다.
